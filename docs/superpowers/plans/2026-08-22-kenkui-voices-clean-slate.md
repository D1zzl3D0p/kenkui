# kenkui-voices Clean-Slate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the scattered voice-pack pipeline with a single `voices.json` on a recreated Hugging Face dataset that carries both curated provenance and generated build records, and make kenkui-v2 resolve the pack against the installed pocket-tts instead of a hardcoded revision.

**Architecture:** Two phases with a hard dependency. Phase 1 (Tasks 1–7) builds the distribution repo at `~/Projects/Repos/kenkui-voices/` — manifest authoring, rebuild/verify/publish tooling — and ends with a full 95-voice rebuild gated on hash-matching the currently published bytes. Phase 2 (Tasks 8–12) changes kenkui-v2's `registry.py` to merge two JSON documents and resolve a version range, developed against fixtures so it does not block on Phase 1. Task 13 performs the irreversible delete-and-recreate and vendors the real manifest.

**Tech Stack:** Python 3.12, uv, pytest, ruff, hatchling, pocket-tts 2.1.0, huggingface_hub, packaging.

**Spec:** `docs/superpowers/specs/2026-08-22-kenkui-voices-clean-slate-design.md`

## Global Constraints

- pocket-tts is pinned `==2.1.0` in kenkui-v2. `tests/test_dependency_contract.py` asserts this; do not change it.
- Python `>=3.11,<3.14`.
- pytest runs with `--strict-config --strict-markers --cov=kenkui --cov-branch --cov-fail-under=90`. A task is not done until the full suite passes at that coverage gate.
- Every function and module needs a docstring (ruff `D` rules). Test modules that omit per-test docstrings put `# ruff: noqa: D103` at the top, following the existing files.
- `kenkui.voices.registry` must open no sockets at import or during catalog access. `tests/test_voice_pack.py::test_loading_the_pack_touches_no_network` enforces this.
- Hugging Face repos are accessed with `hf download` / `huggingface_hub`, never `git clone` — the dataset carries LFS binaries.
- Compiling any prompt requires the gated `kyutai/pocket-tts` weights and an authenticated HF account. Without them pocket-tts falls back to ungated weights and refuses cloning later, far from the cause.
- Two upstream revisions are pinned and must be copied verbatim:

  - `kyutai/pocket-tts-without-voice-cloning` @ `e041936c75475d350b405bc870bcf7c22da4e9e6`
- Dataset repo id: `D1zzl3D0p/kenkui-voices` (`repo_type="dataset"`).
- The preview line, verbatim, unchanged from the published pack:

#!/usr/bin/env python3
# tools/make_voices_json.py
"""One-shot migration: published source manifest -> voices.json.

The published 95-voice manifest records 66 voices against relative upstream
paths and 29 against absolute paths into a Hugging Face cache snapshot. Those
29 WAVs are locally trimmed, Adobe-enhanced derivations that exist on one
machine. Every one of their speakers has upstream audio, so they are rewritten
to `ears/{speaker}/freeform_speech_01_enhanced.wav` -- the same file the 19
already-upstream EARS voices use. The local prompt tier disappears rather than
being versioned.

    uv run python make_voices_json.py SOURCE_MANIFEST OUT

Run once during migration. Thereafter voices.json is the source of truth and
this script is history.
"""

from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any

PROMPT_REPO = "kyutai/tts-voices"
SCHEMA_VERSION = 2
POCKET_TTS_RANGE = ">=2.0.0,<3.0.0"
PREVIEW_TEXT = (
    "It is a truth universally acknowledged, that a single man in possession "
    "of a good fortune, must be in want of a wife."
)
ASSETS_REPO = "D1zzl3D0p/kenkui-voices"


def upstream_prompt(source_voice: dict[str, Any]) -> str:
    """Return the repo-relative prompt path for one source-manifest entry."""
    prompt = source_voice["prompt_source"]
    if not prompt.startswith("/"):
        return prompt
    speaker = source_voice.get("speaker_id")
    if not speaker:
        message = (
            f"{source_voice['voice_id']} has a machine-local prompt and no "
            f"speaker_id, so its upstream audio cannot be located"
        )
        raise ValueError(message)
    return f"ears/{speaker.lower()}/freeform_speech_01_enhanced.wav"


def to_record(source_voice: dict[str, Any]) -> dict[str, Any]:
    """Return one curated voices.json record.

    The compiled and preview blocks are absent until a build writes them: a
    voice without a compiled block is unpublished, which is a state the
    consumer already tolerates.
    """
    return {
        "voice_id": source_voice["voice_id"],
        "display_name": source_voice["display_name"],
        "dataset": source_voice["dataset"],
        "speaker_id": source_voice.get("speaker_id"),
        "gender": source_voice["gender"],
        "accent": source_voice.get("accent"),
        "language": "english",
        "pool_enabled": bool(source_voice.get("pool_enabled", True)),
        "license_id": source_voice["license_id"],
        "commercial_use_allowed": bool(source_voice["commercial_use_allowed"]),
        "voice_rights": source_voice["voice_rights"],
        "source": {"repo_id": PROMPT_REPO, "path": upstream_prompt(source_voice)},
    }


def build_document(source_voices: list[dict[str, Any]]) -> dict[str, Any]:
    """Assemble the whole voices.json document."""
    return {
        "schema_version": SCHEMA_VERSION,
        "pocket_tts": POCKET_TTS_RANGE,
        "verified_versions": [],
        "built_with": None,
        "preview_text": PREVIEW_TEXT,
        "assets": {
            "repo_id": ASSETS_REPO,
            "repo_type": "dataset",
            "revision": None,
        },
        "voices": [to_record(voice) for voice in source_voices],
    }


def main() -> int:
    """Read the published source manifest and write voices.json."""
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("source_manifest", type=Path)
    parser.add_argument("out", type=Path)
    args = parser.parse_args()

    payload = json.loads(args.source_manifest.read_text(encoding="utf-8"))
    voices = payload["voices"] if isinstance(payload, dict) else payload
    document = build_document(voices)
    args.out.write_text(
        json.dumps(document, indent=2, sort_keys=True) + "\n", encoding="utf-8"
    )
    rewritten = sum(1 for v in voices if v["prompt_source"].startswith("/"))
    print(f"wrote {args.out} with {len(document['voices'])} voices")
    print(f"{rewritten} machine-local prompts rewritten to upstream")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

# tools/lock.py
"""Read the pinned upstream sources.

A prompt is only reproducible if the revision it came from is recorded. An
unpinned repo is a failure, not a fall-through to `main`.
"""

from __future__ import annotations

import json
from pathlib import Path


def load_lock(path: Path) -> dict[str, str]:
    """Return the repo_id -> revision mapping from sources.lock.json."""
    payload = json.loads(path.read_text(encoding="utf-8"))
    return {entry["repo_id"]: entry["revision"] for entry in payload["sources"]}


def revision_for(lock: dict[str, str], repo_id: str) -> str:
    """Return the pinned revision for one repo, or raise naming it."""
    try:
        return lock[repo_id]
    except KeyError:
        message = f"{repo_id} is not pinned in sources.lock.json"
        raise KeyError(message) from None
```

#!/usr/bin/env python3
# tools/rebuild.py
"""Recompile voices from their pinned upstream prompts.

    uv run python rebuild.py [--voice ID]... [--all] [--check] [--force]

Reads voices.json, materializes each prompt from the revision pinned in
sources.lock.json, compiles it against the *installed* pocket-tts, renders a
preview, and rewrites the generated `compiled` and `preview` blocks in place.

--check compiles into a temporary directory and diffs against the recorded
hashes without writing anything. That is the fast answer to "do the published
safetensors still work with this pocket-tts".

Compiling a WAV prompt is voice cloning and needs the gated kyutai/pocket-tts
weights. pocket-tts otherwise falls back to ungated weights and refuses the
audio prompt later, far from the cause, so this checks up front.
"""

from __future__ import annotations

import argparse
import hashlib
import json
import math
import struct
import sys
import tempfile
import wave
from pathlib import Path
from typing import Any, NoReturn

from huggingface_hub import hf_hub_download

from lock import load_lock, revision_for

PREVIEW_ATTEMPTS = 5
MIN_PREVIEW_MS = 500
MAX_PREVIEW_MS = 30_000
MAX_PREVIEW_CHARS_PER_SECOND = 30
CLIP_LEVEL = 0.999
MAX_CLIPPED_FRACTION = 0.01


class RetryablePreviewError(ValueError):
    """A stochastic preview failure that a fresh generation may not repeat."""


def fail(message: str) -> NoReturn:
    """Exit with a message that names the fix rather than the symptom."""
    sys.exit(f"ERROR: {message}")


def digest(path: Path) -> str:
    """Return the SHA-256 of a file, read in bounded chunks."""
    hasher = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            hasher.update(chunk)
    return hasher.hexdigest()


def resolve_prompt(source: dict[str, str], lock: dict[str, str]) -> Path:
    """Materialize one prompt WAV at its pinned revision."""
    revision = revision_for(lock, source["repo_id"])
    return Path(
        hf_hub_download(
            repo_id=source["repo_id"], filename=source["path"], revision=revision
        )
    )


def load_model() -> Any:
    """Load cloning-capable pocket-tts weights, or explain why they are absent."""
    try:
        from pocket_tts.models.tts_model import TTSModel
    except ImportError:
        fail("pocket-tts is not installed in this interpreter")
    model = TTSModel.load_model(language="english")
    if not getattr(model, "has_voice_cloning", False):
        fail(
            "loaded pocket-tts weights cannot clone voices, so no prompt can be "
            "compiled. Accept the terms at https://huggingface.co/kyutai/"
            "pocket-tts and authenticate, then re-run."
        )
    return model


def compile_voice(model: Any, source: Path, destination: Path) -> None:
    """Compile one prompt into a speaker embedding."""
    from pocket_tts import export_model_state

    destination.parent.mkdir(parents=True, exist_ok=True)
    state = model.get_state_for_audio_prompt(source)
    export_model_state(state, destination)


def check_preview(samples: list[float], rate: int, text: str) -> None:
    """Reject a preview that cannot plausibly be the requested phrase.

    The silent failure mode is the model running to its generation limit
    without emitting EOS and returning well-formed audio containing no words.
    Duration is the cheap signal for it.
    """
    if not samples:
        message = "preview audio is empty"
        raise RetryablePreviewError(message)
    if not all(math.isfinite(value) for value in samples):
        message = "preview audio contains non-finite samples"
        raise RetryablePreviewError(message)
    duration_ms = len(samples) * 1000 / rate
    floor_ms = max(MIN_PREVIEW_MS, len(text) * 1000 / MAX_PREVIEW_CHARS_PER_SECOND)
    if duration_ms < floor_ms:
        message = f"preview is {duration_ms:.0f}ms, too short for {len(text)} chars"
        raise RetryablePreviewError(message)
    if duration_ms > MAX_PREVIEW_MS:
        message = f"preview is {duration_ms:.0f}ms, likely generated without EOS"
        raise RetryablePreviewError(message)
    clipped = sum(1 for value in samples if abs(value) >= CLIP_LEVEL)
    if clipped / len(samples) > MAX_CLIPPED_FRACTION:
        message = "preview audio has obvious clipping"
        raise RetryablePreviewError(message)


def render_preview(model: Any, compiled: Path, destination: Path, text: str) -> int:
    """Render the preview line in the compiled voice, returning its duration."""
    destination.parent.mkdir(parents=True, exist_ok=True)
    state = model.get_state_for_audio_prompt(compiled)
    rate = int(model.sample_rate)
    last: RetryablePreviewError | None = None
    for _attempt in range(PREVIEW_ATTEMPTS):
        audio = model.generate_audio(state, text)
        samples = audio.detach().cpu().flatten().tolist()
        try:
            check_preview(samples, rate, text)
        except RetryablePreviewError as error:
            last = error
            continue
        break
    else:
        message = f"preview repeatedly failed validation: {last}"
        raise ValueError(message)
    frames = b"".join(
        struct.pack("<h", round(max(-1.0, min(float(value), 1.0)) * 32767.0))
        for value in samples
    )
    with wave.open(str(destination), "wb") as handle:
        handle.setnchannels(1)
        handle.setsampwidth(2)
        handle.setframerate(rate)
        handle.writeframes(frames)
    return len(samples) * 1000 // rate


def update_record(
    record: dict[str, Any],
    compiled: Path,
    preview: dict[str, Any] | None,
    prompt_sha: str,
) -> dict[str, Any]:
    """Return the record with only its generated blocks rewritten."""
    updated = dict(record)
    updated["source"] = {**record["source"], "sha256": prompt_sha}
    updated["compiled"] = {
        "path": f"compiled/{compiled.name}",
        "sha256": digest(compiled),
        "size_bytes": compiled.stat().st_size,
    }
    if preview is not None:
        updated["preview"] = preview
    return updated


def installed_pocket_version() -> str:
    """Return the installed pocket-tts version."""
    from importlib import metadata

    return metadata.version("pocket-tts")


def rebuild(  # noqa: PLR0913 - one call site; each flag is an independent knob.
    root: Path,
    *,
    only: set[str] | None = None,
    check: bool = False,
    force: bool = False,
    previews: bool = True,
) -> int:
    """Compile the selected voices and rewrite voices.json. Returns exit code."""
    manifest_path = root / "voices.json"
    document = json.loads(manifest_path.read_text(encoding="utf-8"))
    lock = load_lock(root / "sources.lock.json")
    preview_text = document["preview_text"]
    version = installed_pocket_version()

    with tempfile.TemporaryDirectory() as scratch:
        out = Path(scratch) if check else root
        compiled_dir = out / "compiled"
        preview_dir = out / "previews"
        compiled_dir.mkdir(parents=True, exist_ok=True)

        selected = [
            voice
            for voice in document["voices"]
            if only is None or voice["voice_id"] in only
        ]
        print(f"{len(selected)} voice(s) selected, pocket-tts {version}")

        model = None
        records: dict[str, dict[str, Any]] = {}
        mismatches: list[str] = []
        failures: list[str] = []

        for index, voice in enumerate(selected, start=1):
            voice_id = voice["voice_id"]
            compiled = compiled_dir / f"{voice_id}.safetensors"
            if compiled.is_file() and not force and not check:
                print(f"[{index}/{len(selected)}] reusing {voice_id}")
                continue
            print(f"[{index}/{len(selected)}] compiling {voice_id}")
            try:
                prompt = resolve_prompt(voice["source"], lock)
                prompt_sha = digest(prompt)
                recorded = voice["source"].get("sha256")
                if recorded is not None and recorded != prompt_sha:
                    message = (
                        f"{voice_id}: upstream prompt changed under a pinned "
                        f"revision (recorded {recorded[:12]}, got {prompt_sha[:12]})"
                    )
                    fail(message)
                if model is None:
                    model = load_model()
                compile_voice(model, prompt, compiled)
            except SystemExit:
                raise
            except Exception as error:
                # One bad voice must not abandon the other ninety-four.
                print(f"    FAILED: {type(error).__name__}: {error}")
                failures.append(voice_id)
                continue

            if check:
                expected = (voice.get("compiled") or {}).get("sha256")
                actual = digest(compiled)
                status = "MATCH" if expected == actual else "DIFFER"
                print(f"    {status} {actual[:12]} (recorded {str(expected)[:12]})")
                if expected != actual:
                    mismatches.append(voice_id)
                continue

            preview_entry: dict[str, Any] | None = voice.get("preview")
            if previews:
                preview_file = preview_dir / f"{voice_id}.wav"
                try:
                    duration = render_preview(
                        model, compiled, preview_file, preview_text
                    )
                    preview_entry = {
                        "path": f"previews/{preview_file.name}",
                        "sha256": digest(preview_file),
                        "duration_ms": duration,
                        "text": preview_text,
                    }
                except Exception as error:
                    # A missing preview is cosmetic; the voice still renders.
                    print(f"    preview failed: {type(error).__name__}: {error}")
            records[voice_id] = update_record(
                voice, compiled, preview_entry, prompt_sha
            )

        if check:
            print(f"\n{len(mismatches)} mismatch(es), {len(failures)} failure(s)")
            for voice_id in mismatches:
                print(f"  DIFFERS: {voice_id}")
            return 1 if mismatches or failures else 0

        document["voices"] = [
            records.get(voice["voice_id"], voice) for voice in document["voices"]
        ]
        document["built_with"] = version
        if version not in document["verified_versions"]:
            document["verified_versions"] = sorted(
                [*document["verified_versions"], version]
            )
        manifest_path.write_text(
            json.dumps(document, indent=2, sort_keys=True) + "\n", encoding="utf-8"
        )
        published = sum(1 for v in document["voices"] if v.get("compiled"))
        print(f"\nwrote {manifest_path}: {published}/{len(document['voices'])} published")
        if failures:
            print(f"{len(failures)} voice(s) failed and carry no compiled block")
        return 1 if failures else 0


def main() -> int:
    """Parse arguments and run the rebuild."""
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=Path(__file__).parent.parent)
    parser.add_argument("--voice", action="append", dest="voices", default=[])
    parser.add_argument("--all", action="store_true")
    parser.add_argument("--check", action="store_true")
    parser.add_argument("--force", action="store_true")
    parser.add_argument("--no-previews", action="store_true")
    args = parser.parse_args()
    if not args.voices and not args.all:
        parser.error("pass --voice ID (repeatable) or --all")
    return rebuild(
        args.root,
        only=set(args.voices) or None,
        check=args.check,
        force=args.force,
        previews=not args.no_previews,
    )


if __name__ == "__main__":
    raise SystemExit(main())

#!/usr/bin/env python3
# tools/verify.py
"""Check whether the published embeddings still match a pocket-tts release.

    uv run python verify.py [--all]

Compiles one VCTK and one EARS voice against the installed pocket-tts and
diffs the hashes against voices.json. Semantic versioning is a promise about
API, not artifact format, and kyutai documents no embedding stability, so a
new release is verified rather than assumed. Run on demand when a new
pocket-tts appears -- not in CI, which has no gated weights.
"""

from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any

from rebuild import installed_pocket_version, rebuild


def sample_voice_ids(document: dict[str, Any]) -> list[str]:
    """Return one voice_id per corpus, in corpus order."""
    seen: dict[str, str] = {}
    for voice in document["voices"]:
        seen.setdefault(voice["dataset"], voice["voice_id"])
    return [seen[dataset] for dataset in sorted(seen)]


def widen_message(document: dict[str, Any], version: str) -> str:
    """Return the voices.json edit that records this version as verified."""
    known = list(document.get("verified_versions", []))
    if version in known:
        return f"pocket-tts {version} is already recorded in verified_versions"
    widened = json.dumps(sorted([*known, version]))
    return (
        f"All sampled hashes match under pocket-tts {version}.\n"
        f"Apply this edit to voices.json:\n"
        f'  "verified_versions": {widened}'
    )


def main() -> int:
    """Compile the sample and report whether the pack still holds."""
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=Path(__file__).parent.parent)
    parser.add_argument(
        "--all", action="store_true", help="verify all 95, as a major bump warrants"
    )
    args = parser.parse_args()

    document = json.loads((args.root / "voices.json").read_text(encoding="utf-8"))
    version = installed_pocket_version()
    only = None if args.all else set(sample_voice_ids(document))
    code = rebuild(args.root, only=only, check=True, previews=False)
    if code == 0:
        print()
        print(widen_message(document, version))
    else:
        print()
        print(
            f"pocket-tts {version} does NOT reproduce the published embeddings. "
            f"Investigate before shipping: a format change here is inaudible to "
            f"the code."
        )
    return code


if __name__ == "__main__":
    raise SystemExit(main())

#!/usr/bin/env python3
# tools/publish.py
"""Upload the pack and stamp the revision its manifest pins.

    uv run python publish.py [--repo-id REPO]

voices.json records the revision of the commit carrying compiled/ and
previews/. It cannot name the commit it is itself part of, so this uploads in
two: the binaries first, then the manifest pointing back at them. The manifest
commit is always a descendant of the one it pins, which is the right way round
-- what needs pinning is the bytes.
"""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path
from typing import Any

ASSET_PATTERNS = ["compiled/*", "previews/*"]
TEXT_PATTERNS = ["voices.json", "sources.lock.json", "README.md", "tools/*", "tools/tests/*"]


def stamp_assets_revision(
    document: dict[str, Any], repo_id: str, revision: str
) -> dict[str, Any]:
    """Return the document with its assets block pinned to one revision."""
    stamped = dict(document)
    stamped["assets"] = {
        "repo_id": repo_id,
        "repo_type": "dataset",
        "revision": revision,
    }
    return stamped


def publish(root: Path, repo_id: str, api: Any) -> str:
    """Upload assets, then the manifest pinning them. Returns the revision."""
    manifest_path = root / "voices.json"
    document = json.loads(manifest_path.read_text(encoding="utf-8"))
    published = [voice for voice in document["voices"] if voice.get("compiled")]
    if not published:
        sys.exit("ERROR: no voice has a compiled block; run rebuild.py --all first")

    api.upload_folder(
        folder_path=str(root),
        repo_id=repo_id,
        repo_type="dataset",
        allow_patterns=ASSET_PATTERNS,
        commit_message=f"Publish {len(published)} compiled voices",
    )
    revision = str(api.repo_info(repo_id, repo_type="dataset").sha)

    stamped = stamp_assets_revision(document, repo_id, revision)
    manifest_path.write_text(
        json.dumps(stamped, indent=2, sort_keys=True) + "\n", encoding="utf-8"
    )
    api.upload_folder(
        folder_path=str(root),
        repo_id=repo_id,
        repo_type="dataset",
        allow_patterns=TEXT_PATTERNS,
        commit_message=f"Manifest for assets {revision[:8]}",
    )
    return revision


def main() -> int:
    """Publish the pack and print what kenkui-v2 should vendor."""
    from huggingface_hub import HfApi

    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=Path(__file__).parent.parent)
    parser.add_argument("--repo-id", default="D1zzl3D0p/kenkui-voices")
    args = parser.parse_args()

    revision = publish(args.root, args.repo_id, HfApi())
    print(f"\npublished {args.repo_id} @ {revision}")
    print("vendor it into kenkui-v2 with:")
    print(
        f"  cp {args.root / 'voices.json'} "
        f"kenkui/src/kenkui/voices/pack.json"
    )
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from packaging.version import InvalidVersion, Version

_PACK_MANIFEST: Final = Path(__file__).with_name("pack.json")
_REBUILD_HINT: Final = (

@dataclass(frozen=True, slots=True)
class PackLoad:
    """The pack as resolved against the installed pocket-tts.

    `incompatible` is None when the pack loaded or was simply absent, and a
    message naming both versions when the pack exists but cannot be used. The
    distinction matters: an absent pack is a degraded install, an incompatible
    one is a misconfiguration that must not fail quietly.
    """

    entries: tuple[CatalogEntry, ...]
    incompatible: str | None


def installed_pocket_version() -> str:
    """Return the installed pocket-tts version."""
    return metadata.version("pocket-tts")


def _incompatibility(declared: str) -> str | None:
    """Return why the installed pocket-tts cannot use this pack, or None."""
    installed = installed_pocket_version()
    try:
        if Version(installed) in SpecifierSet(declared):
            return None
    except (InvalidSpecifier, InvalidVersion):
        return (
            f"the voice pack declares an unreadable pocket-tts range "
            f"{declared!r}; installed is {installed}. {_REBUILD_HINT}"
        )
    return (
        f"the voice pack was compiled for pocket-tts {declared} but "
        f"{installed} is installed. Its embeddings would load without error "
        f"and render audio containing no words. {_REBUILD_HINT}"
    )


def _pack_entry(
    voice: dict[str, Any], voice_id: str, assets: dict[str, str]
) -> CatalogEntry:
    """Convert one pack manifest record into a catalog entry."""
    repo = assets["repo_id"]
    revision = assets["revision"]
    return CatalogEntry(
        id=voice_id,
        name=voice["display_name"],
        language=voice["language"],
        origin_url=f"hf://{voice['source']['repo_id']}/{voice['source']['path']}",
        license_id=voice["license_id"],
        commercial_use_allowed=bool(voice["commercial_use_allowed"]),
        voice_rights=voice["voice_rights"],
        asset_url=f"hf://{repo}/{voice['compiled']['path']}@{revision}",
        perceived_gender=_GENDERS.get(voice["gender"]),
    )


@lru_cache(maxsize=1)
def load_pack() -> PackLoad:
    """Read the bundled voice pack and resolve it against pocket-tts.

    Static package data, not a network or user source: no request is made and
    no path comes from a caller. A missing or unreadable manifest degrades to
    the built-in catalog rather than failing an import, because the pack is an
    addition and Kenkui must work without it. A pack that is present but
    compiled for a different pocket-tts major is a different matter: its
    voices are withheld and the reason is kept, so using one raises instead of
    rendering silence.
    """
    try:
        payload = json.loads(_PACK_MANIFEST.read_text(encoding="utf-8"))
        voices = payload["voices"]
        assets = payload["assets"]
        declared = payload["pocket_tts"]
    except (OSError, ValueError, KeyError, TypeError):
        return PackLoad((), None)

    incompatible = _incompatibility(declared)
    if incompatible is not None:
        return PackLoad((), incompatible)

    built_in = {entry.id for entry in load_builtin()}
    entries: list[CatalogEntry] = []
    for voice in voices:
        # A voice with no compiled block is unpublished: a gap in the pack,
        # not a reason to abandon the other ninety-four.
        if not voice.get("compiled"):
            continue
        # Short display names read far better at a call site than the full
        # slug. Where one would shadow a built-in the pack voice keeps its
        # slug: they are different speakers who happen to share a name, so
        # dropping either would lose a voice.
        short = str(voice["display_name"]).lower()
        entries.append(
            _pack_entry(
                voice, voice["voice_id"] if short in built_in else short, assets
            )
        )
    return PackLoad(tuple(entries), None)


@lru_cache(maxsize=1)
def _withheld_pack_ids() -> frozenset[str]:
    """Return the voice IDs an incompatible pack is keeping out of the catalog."""
    if load_pack().incompatible is None:
        return frozenset()
    try:
        payload = json.loads(_PACK_MANIFEST.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return frozenset()
    ids: set[str] = set()
    for voice in payload.get("voices", ()):
        ids.add(voice["voice_id"])
        ids.add(str(voice["display_name"]).lower())
    return frozenset(ids)


def pack_voice_guard(voice_id: str) -> None:
    """Raise if this ID names a voice an incompatible pack is withholding."""
    reason = load_pack().incompatible
    if reason is not None and voice_id in _withheld_pack_ids():
        raise VoiceError(ErrorCode.VOICE_INCOMPATIBLE, reason)
